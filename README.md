# SIDEDAII

Sistema Didáctico de Estructuras de Datos y Algoritmos II.

Proyecto académico desarrollado con Java 11, Maven, Swing y arquitectura MVC.

## Pantallas incluidas

1. Pantalla de bienvenida.
2. Menú principal con los módulos:
   - Eficiencia algorítmica.
   - Análisis de complejidad.
   - P, NP, NP-Hard y NP-Completo.
   - Teoría de grafos.

## Ejecución en Eclipse

1. Importar el proyecto mediante **File > Import > Maven > Existing Maven Projects**.
2. Seleccionar la carpeta del proyecto y finalizar.
3. Abrir `src/main/java/ec/edu/epn/sidedaii/Main.java`.
4. Ejecutar como **Java Application**.

El logo se encuentra en `src/main/resources/imagenes/logo-epn.png`.
